# BASEFROM50 FREE GUIDE — project context

## What this is
A free PDF lead magnet for BASEFROM50. It replaces a long mandatory free-learning step with a fast, useful document.

## Funnel job
The reader should quickly understand a practical buying system:
1. find the item,
2. choose the right size / seller,
3. calculate the full cost,
4. pay / order,
5. receive the item.

The guide should create an immediate "I can use this" feeling and then point to the paid BASEFROM50 base for deeper instructions, suppliers, platforms, tables and calculations.

## Audience
Primarily young people interested in clothing, sneakers and buying for themselves without overpaying. The tone should be simple, confident and non-corporate.

## Positioning
Not "a course you must complete".
Not generic motivation.
It is a compact operating manual / cheat sheet.

## Design
The current target is a premium fashion editorial / streetwear magazine feel:
- black and off-white
- bold typography
- high contrast
- asymmetric layouts
- premium, technical, slightly underground
- visually closer to a contemporary fashion publication than a business PDF

Avoid template-looking reports, oversized rounded cards, generic gradients and obvious AI aesthetics.

## Technical decision
HTML + CSS -> Playwright / Chromium -> PDF.
Do not use ReportLab as the primary layout engine.

## Current draft
The repository contains a complete 6-page first edition. Treat its text as editable draft copy. Improve design first without losing the funnel logic.
