# BASEFROM50 Free Guide

Premium editorial PDF lead magnet.

## Build locally or in Codex Cloud

```bash
cd free-guide
npm install
npx playwright install chromium
npm run pdf
```

Output:
`output/basefrom50-free-guide.pdf`
