# Skill: BASEFROM50 Editorial PDF

Use this skill whenever working on the BASEFROM50 free guide.

## Outcome
Produce a visually expensive, modern fashion/editorial PDF in Russian that can act as a lead magnet and transition into the paid BASEFROM50 product.

## Visual direction
- premium streetwear editorial
- black / off-white base with one restrained warm accent
- high contrast
- oversized headlines
- strong whitespace
- asymmetric composition
- editorial page numbers / small technical labels
- subtle grid, rules, captions, price formulas, checklists
- avoid rounded SaaS cards, gradients, glassmorphism, stock-corporate look
- avoid dense walls of text
- no childish "course" aesthetic

## Typography
Use a strong grotesk/sans stack for headlines and readable sans for body. A serif may be used sparingly for editorial contrast. Prioritize Cyrillic support.

## Layout rules
- A4 portrait, 210 x 297 mm
- 12–16 mm safe margins
- 6–8 column mental grid
- one dominant visual idea per page
- body copy normally 10–12pt equivalent
- no content may cross page boundaries
- create deliberate rhythm: dense page → airy page → dense page

## Brand / funnel context
BASEFROM50 teaches people how to buy clothing more intelligently, including finding products, calculating full landed cost, ordering and delivery. The free guide should give real value but make the paid base feel like the natural next step, not a hard sell.

## Content treatment
Prefer concrete examples, formulas, checklists and "do this / avoid this" guidance. Remove filler. Make Russian copy natural and direct.

## QA before completion
- run `npm run pdf`
- check that PDF exists
- render or screenshot all pages if tools permit
- verify page count
- inspect for clipping, widows/orphans, accidental empty pages, missing fonts
- ensure CTA is clear on final page
