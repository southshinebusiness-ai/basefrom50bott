# Design-method sources

These are research references used to build the project-local design director. They are not copied wholesale into this repository.

1. Anthropic — Frontend Design
   https://github.com/anthropics/claude-code/blob/main/plugins/frontend-design/skills/frontend-design/SKILL.md
   Key use: avoid template defaults; deliberate palette/type/layout; plan -> critique -> build.

2. SkillMedev — Typography System
   https://github.com/SkillMedev/skills/blob/main/skills/typography-system/SKILL.md
   Key use: define type roles first; max two families; modular scale; line-height and measure.

3. SkillMedev — Visual Hierarchy
   https://github.com/SkillMedev/skills/blob/main/skills/visual-hierarchy/SKILL.md
   Key use: one focal point; three hierarchy levels; size -> weight -> color -> position -> whitespace; squint test.

4. SkillMedev — Design Critique
   https://github.com/SkillMedev/skills/blob/main/skills/design-critique/SKILL.md
   Key use: critique by job, clarity, delight; severity-ranked fixes.

5. dawitlabs — design-grill
   https://github.com/dawitlabs/ui-skills/blob/master/skills/design-grill/SKILL.md
   Key use: resolve visual direction before implementation; reject vague aesthetic language.

6. dawitlabs — uicolor
   https://github.com/dawitlabs/ui-skills/blob/master/skills/uicolor/SKILL.md
   Key use: color-role balance; dominant/secondary/accent; temperature consistency; rendered palette audit.

7. MengTo — Editorial Tech
   https://github.com/MengTo/Skills/blob/main/agent-skills/web-design/editorial-tech/SKILL.md
   Key use: editorial asymmetry + precise technical detailing; restrained accent; non-generic layout.
